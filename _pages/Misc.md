* I was born and brought up in <span style ="color:blue">[Calcutta (now Kolkata)](https://en.wikipedia.org/wiki/Kolkata)</span>, <span style ="color:blue">[West Bengal](https://en.wikipedia.org/wiki/West_Bengal)</span>, <span style ="color:blue">[India](https://en.wikipedia.org/wiki/India)</span>. My family has roots in <span style ="color:blue">[Lalbag](https://en.wikipedia.org/wiki/Lalbag_subdivision)</span>, <span style ="color:blue">[Berhampore](https://en.wikipedia.org/wiki/Berhampore)</span> and Barahatti in <span style ="color:blue">[Murshidabad district, WB](https://en.wikipedia.org/wiki/Murshidabad_district)</span>, and in <span style ="color:blue">[Katwa](https://en.wikipedia.org/wiki/Katwa)</span> in <span style ="color:blue">[Purba Bardhaman district, WB](https://en.wikipedia.org/wiki/Purba_Bardhaman_district)</span>. 

* I enjoy photography, travelling and trekking. 

* I listen to <span style ="color:blue">[Hindustani classical music](https://en.wikipedia.org/wiki/Hindustani_classical_music)</span>, especially the sitar of <span style ="color:blue">[Ustad Vilayat Khan](https://en.wikipedia.org/wiki/Vilayat_Khan)</span> and <span style ="color:blue">[Pandit Ravi Shankar](https://en.wikipedia.org/wiki/Ravi_Shankar)</span>. 

* I grew up reading Bengali novels and poetry by <span style ="color:blue">[Bankim Chandra Chattopadhyay](https://en.wikipedia.org/wiki/Bankim_Chandra_Chatterjee)</span>, <span style ="color:blue">[Sarat Chandra Chattopadhyay](https://en.wikipedia.org/wiki/Sarat_Chandra_Chattopadhyay)</span>, <span style ="color:blue">[Rabindranath Tagore](https://en.wikipedia.org/wiki/Rabindranath_Tagore)</span>, <span style ="color:blue">[Bibhutibhushan Bandyopadhyay](https://en.wikipedia.org/wiki/Bibhutibhushan_Bandyopadhyay)</span>, <span style ="color:blue">[Sharadindu Bandyopadhyay](https://en.wikipedia.org/wiki/Sharadindu_Bandyopadhyay)</span>, <span style ="color:blue">[Tarasankar Bandyopadhyay](https://en.wikipedia.org/wiki/Tarasankar_Bandyopadhyay)</span>, <span style ="color:blue">[Mahasweta Devi](https://en.wikipedia.org/wiki/Mahasweta_Devi)</span>, <span style ="color:blue">[Shakti Chattopadhyay](https://en.wikipedia.org/wiki/Shakti_Chattopadhyay)</span>, <span style ="color:blue">[Satyajit Ray](https://en.wikipedia.org/wiki/Satyajit_Ray)</span>, <span style ="color:blue">[Shirshendu Mukhopadhyay](https://en.wikipedia.org/wiki/Shirshendu_Mukhopadhyay)</span> and <span style ="color:blue">[Buddhadeb Guha](https://en.wikipedia.org/wiki/Buddhadeb_Guha)</span>, among others. More recently I have been reading Haruki Murakami, Kazuo Ishiguro, Mark Twain, Leo Tolstoy, Edgar Allan Poe, Ernest Hemingway and Charles Dickens.

* I have been meaning to learn an instrument for a long time.
